# Hardware Design Files

Folder ini berisi file desain perangkat keras HerbaDry Monitoring System yang digunakan untuk mendukung proses reproduksi dan pengembangan perangkat.

File yang dapat ditempatkan pada folder ini meliputi:

- Diagram rangkaian elektronik.
- Schematic.
- Layout PCB, jika tersedia.
- Diagram koneksi sensor dan ESP32.
- File desain mekanik.
- Gambar atau dokumentasi perakitan perangkat.

Dokumentasi dan file desain pada folder ini merupakan bagian dari desain open hardware HerbaDry Monitoring System.
